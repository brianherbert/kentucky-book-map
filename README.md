# Kentucky Book Map

An interactive map of Kentucky with pins marking where books are set. Browse the map to find books that take place in places you know or want to explore.

Built with plain HTML, CSS and JavaScript (no build step), so it can be hosted as static files on any website.

## Running it locally

The page loads `books.json` and `data/kentucky.json` with `fetch`, so open it through a web server rather than as a file:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html`, `css/style.css`, `js/map.js`: the page. D3 is vendored in `vendor/`, so nothing loads from a third party.
- `books.json`: the books, one entry each with coordinates, Goodreads link and cover path. Add a book here and it appears on the map.
- `images/covers/`: cover thumbnails, named by each book's `id`.
- `data/kentucky.json`: state outline and county lines, generated by `scripts/build-geo.mjs` from the `us-atlas` package.
- Town names, region names and the sketched rivers are listed at the top of `js/map.js`.
